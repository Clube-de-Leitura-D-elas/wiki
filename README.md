# Wiki — Clube de Leitura D'elas

Base de conhecimento do **Clube de Leitura D'elas**. Este repositório é o ponto central para
decisões de produto, definição de funcionalidades e documentação durável do domínio.

## Propósito

O repositório `wiki` serve como fonte de verdade do Clube de Leitura D'elas. Aqui mora o
contexto que sobrevive a sessões de chat e reuniões: especificações, decisões, modelos de
domínio, glossários e artefatos de planejamento.

## Estrutura

| Pasta | Descrição |
|-------|-----------|
| `contextos/` | Bundle OKF com o conhecimento durável por domínio |
| `templates/` | Modelos de documento e especificações |

## Como Usar

### Para contribuidores humanos

Leia o [AGENTS.md](AGENTS.md) — ele contém as convenções, o vocabulário controlado e o
modelo de frontmatter. Documento novo nasce 100% conforme.

### Para agentes de IA

Este repositório segue o padrão OKF. Comece pelo `contextos/index.md`, navegue pelos links e
use as tags como eixo de consulta transversal. As convenções completas estão no
[AGENTS.md](AGENTS.md).
