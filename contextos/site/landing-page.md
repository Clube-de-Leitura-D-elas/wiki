# Landing page do clube

Página única, pequena e autocontida: a presença do clube na web. Não é parte do MVP do aplicativo nem do painel de gestão — é uma frente de entrega própria, fora das [sprints do roadmap](../planejamento/roadmap.md).

## Papel no funil

- **Destino do link da bio do Instagram**: é aqui que quem descobre o clube — o "conhece o clube" do fluxo da leitora — aterrissa.
- **Porta de entrada para a inscrição**: a página encaminha para o Google Forms mantido pela gestão; a partir daí o fluxo segue o já decidido (Forms → aprovação no painel web → e-mail com código de ativação → aplicativo). Ver [Épicos do MVP — inscrição de novas participantes](../planejamento/epicos-mvp.md).
